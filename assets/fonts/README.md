# Bundled font: DotGothic16

`DotGothic16-Regular.ttf` in this folder is **DotGothic16**, a
dot-matrix-style TrueType font covering Japanese (hiragana, katakana,
kanji) and Latin. MixAble loads it at startup and uses it as the
application-wide font, so every label, button and readout renders in
the same bitmap letterform (pass 12, 2026-11-27).

- **Font:** DotGothic16 Regular

  Authors (https://github.com/fontworks-fonts/DotGothic16)
