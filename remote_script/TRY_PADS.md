# パッドを試す (Remote Script v1.5 → v1.6)

DDJ-RB のパフォーマンスパッド（各デッキ8つ）に、MixAble の演奏機能を
割り当てた試用版だよ。マウス操作なしで、実機のパッドから
ホットキュー／キュー打ち／クオンタイズ／ループができるか確かめるための
もの。判断は全部スクリプト側（ブリッジ）にあって、Live 側は実行だけ。

**v1.6 で追加: BROWSE ノブで曲選択**（下の「BROWSE ノブ」の節）。
差し替えるファイルは v1.5 と同じ3ファイルで、置き場も同じだよ。

## パッドの割り当て（両デッキ共通）

| パッド | 機能 | 動き |
|---|---|---|
| 1〜4 | Hot Cue A〜D | 今の曲のホットキュークリップを発火。点灯 = そのクリップが再生中 |
| 5 | CUE SET | 再生中クリップの頭（スタートマーカー）を今の再生位置にセット。点灯 = 再生中（打ち込み可能） |
| 6 | QUANTIZE | クリップ発火のクオンタイズを「1小節 ⇄ なし」で切り替え。点灯 = 1小節クオンタイズ ON |
| 7 | LOOP IN | ループ開始点を今の位置にセットし、仮の終端（+4拍）でループ開始。点灯 = 終端待ち |
| 8 | LOOP OUT | ループ終端を今の位置に確定。ループ確定後にもう一度押すとループ解除。点灯 = ループ中 |

RB 本来の LOOP IN／OUT ボタン（デッキ脇）は v1.4 のまま
（開始点／終端をそのままセット）で、パッド側とは別に残してあるよ。

## BROWSE ノブで曲選択（v1.6）

中央の BROWSE ノブで、次に掛ける曲をノブだけで選んで出せるよ。

- **回す** ― 対象デッキのクリップを1つずつ移動。Live のセッション
  画面で**ハイライト（選択枠）が動く**のが手がかり（ノブ自体に
  LED はないので、フィードバックは画面のハイライトだけ）。
  先頭／末尾で止まる（ぐるぐる回らない）
- **押し込む** ― ハイライト中のクリップを発火（そのデッキで再生開始）
- **対象デッキは「スタンバイ側」** ― 再生していない方のデッキが
  自動で対象になる（A が再生中なら B を選ぶ、という自然な流れ）。
  両方止まっている／両方鳴っているときは直前の対象のまま。
  最初は A デッキ（クリップがある方）が対象
- **LOAD 1／LOAD 2** ― 対象デッキをそのデッキに固定する
  （選ぶだけ。LOAD では発火しない）。そのデッキのクリップが
  発火すると固定は外れて、スタンバイ側ルールに戻る

試す順番のおすすめ: PLAY で A を出す → BROWSE を回して B 側の
ハイライトが動くのを見る → 押し込んで B の曲が出るか確かめる。

### 正直な留保（BROWSE）

- **ノブの MIDI 番号は未確定（プレースホルダ）**。このリポジトリに
  記録されている DDJ-RB の公式マップには、BROWSE ノブの回転／
  プッシュの番号が**載っていない**（ブラウザ系チャンネルで記録が
  あるのはクロスフェーダー／マスター／フィルター／LOAD だけ）。
  v1.6 は記録のあるブラウザ系チャンネルに仮の番号を置いて配線した
  ので、**回しても何も起きない可能性がある**。その場合は
  慌てなくて大丈夫 ― スクリプトが「未割当のブラウザ系メッセージ」を
  ログに残すようになっているので、ノブを回す／押し込むと、実物の
  番号が Live の `Log.txt` に
  `MixCraft: unmapped browser-channel ...` の行で出る。
  その行を教えてければ、番号を1行直して確定できるよ
- 回転方向（時計回り＝次の曲）は仮定。逆に動いたら、それも
  教えてければ1行で直せるよ

## 試す手順

1. **rekordbox を完全に閉じる**（トレイ常駐も終了。Windows の MIDI
   ポートは1つのアプリしか掴めないため）
2. このブランチの `remote_script/MixCraft/` にある3ファイルを、
   PC のスクリプトフォルダに上書きする:
   - 置き場: `C:\ProgramData\Ableton\Live 10 Suite\Resources\MIDI Remote Scripts\MixCraft\`
   - 対象: `MixCraft.py` / `_live_bridge.py` / `_midi_map.py`
     （`__init__.py` は変更なし）
3. **Live を起動**し、保存済みのテンプレートセットを開く
   （デッキに試しクリップ入り、Cue Out 3/4＋Cue モードのもの）
4. スクリプトが読み込まれると、両デッキとも **パッド6が点灯**
   しているはず（クオンタイズ ON の初期状態）

## 試し方のおすすめ順

1. **PLAY で曲を出す** → パッド1〜4を押す。今のテンプレート
   （手置きの試しクリップ）では、パッドの番号どおりデッキの
   1〜4番目のクリップが発火する（後述の「正直な留保」参照）。
   再生中のクリップのパッドが点灯するよ
2. 再生中に **パッド5（CUE SET）** を押す → その位置がクリップの
   頭になる。デッキの CUE ボタンを押すと、そこに戻るのが正解
3. **パッド6（QUANTIZE）** を押す → LED が消えて、クリップ発火が
   小節待ちなし（即時）に変わる。もう一度押すと 1小節に戻る
4. 再生中に **パッド7（LOOP IN）→ 数拍おいて パッド8（LOOP OUT）**
   → その範囲でループする。パッド8が点灯した状態でもう一度
   パッド8を押すとループ解除

## 正直な留保（試す前に）

- **ホットキューは下ごしらえ次第**。曲ごとに「本編クリップ＋
  ホットキュークリップ（`曲名 – Hot Cue A` のような名前）」が
  並んだセット（als_writer が将来作る形）では、パッド1〜4は
  「今の曲」のホットキューを正しく打つ。今の手置きテンプレートでは
  曲のまとまりを判別できないため、**パッド番号＝デッキのクリップ
  番号**のフォールバック動作になる（これは仕様どおり）
- CUE SET の吸着は **1拍単位**（小節単位ではない）。クオンタイズ
  OFF のときは位置そのままにセットする
- QUANTIZE の初期状態は「ON（1小節）」と**仮定**して始める。
  セット側が OFF で保存されていた場合、最初の1回は押しても
  変わらなく見える（2回目から一致する）
- ループ／キューの編集は **その場のクリップに対する変更**で、
  音声ファイル自体は一切触らない。セットを保存しなければ残らない
- パッドの LED は PLAY と同じく「ベロシティ127＝点灯」の前提
  （実機での最終確認は むぅちゃん の目と耳）
