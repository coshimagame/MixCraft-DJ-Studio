# MixCraft テンプレート Set 作成ガイド

DDJ-RB + MixCraft Remote Script で DJ するための「土台の Live Set」を
1回だけ作ってテンプレート保存する手順。所要 5〜10 分。
このテンプレートから始めれば、毎回デバイスを並べ直す必要がなくなる。

前提の構成（スクリプト側の決め打ち）:

- トラック 1 = Deck A、トラック 2 = Deck B
- 各デッキトラックに Utility / EQ Three / Auto Filter の3つ
- クロスフェーダー割当: Deck A → A、Deck B → B
- Master Out = 1/2、Cue Out = 3/4（DDJ-RB ASIO）

## 1. 準備

1. **rekordbox を完全に終了**する（トレイ常駐分も含む）。Windows の
   MIDI ポートは単一クライアントで、rekordbox が DDJ-RB を掴んで
   いると Live に MIDI が届かない。
2. Live を起動する。
3. 環境設定 → MIDI で、コントロールサーフェイスの行（5行目）に
   **MixCraft** が選ばれ、入力・出力が両方 **DDJ-RB** になっている
   ことを確認する。
4. 新規の空のセットを開く（ファイル → 新規 Live Set）。

## 2. デッキトラックを作る

1. 初期セットではトラック 1・2 が MIDI トラックになっているので、
   両方とも削除する（トラック名の所を右クリック → 削除）。
   Audio トラック2本がトラック 1・2 に繰り上がる。
2. （任意）トラック 1 を **Deck A**、トラック 2 を **Deck B** に
   名前変更する（トラック名を右クリック → 名称変更）。

## 3. 各デッキにデバイスを3つ入れる

トラック 1・2 の**両方**に、Live のブラウザ（左側）から
Audio Effects をこの順でドラッグして入れる:

1. **Utility**（スクリプトの TRIM がこの Gain を動かす）
2. **EQ Three**（スクリプトの EQ HI / MID / LOW が動かす）
3. **Auto Filter**（スクリプトの FILTER が動かす）

スクリプトはデバイスを種類と名前で探すので、3つが揃っていれば
チェーン内の順番はこの通りでなくても動く。迷ったらこの順で。

## 4. ミキサーの設定

1. Session ビューで、各トラック下部のクロスフェーダー割当ボタン:
   - トラック 1（Deck A）→ **A**
   - トラック 2（Deck B）→ **B**
2. 環境設定 → オーディオで出力設定を確認する:
   - Master Out = **1/2**
   - Cue Out = **3/4**
   
   この2つは Live Set ごとに保存される設定なので、テンプレートに
   含めるには「このセットの状態で」保存する必要がある（手順 6）。

## 5. セット BPM を決める

1. 左上のテンポ表示に、セット全体の固定 BPM を入力する: **＿＿＿ BPM**
   （自分で決めた値を書き込んで、その値に設定する）
2. セット中はこの BPM を動かさない運用。DDJ-RB のテンポ
   スライダーはスクリプトが意図的に無視するので、触っても
   テンポは変わらない（事故防止）。

## 6. テンプレートとして保存

1. ファイル → **テンプレートとして Live Set を保存...**
   （Save Live Set As Template...）を実行する。
2. 次回からは、このテンプレートから新規セットを作れば、
   デバイス・割当・Cue Out・BPM が全部揃った状態で始められる。

## 7. 朝の確認リスト

テンプレートから新規セットを作り、両デッキに曲を入れて確認する。

- [ ] **TRIM**: RB の TRIM を回すと、そのデッキの Utility の
      Gain が動く
- [ ] **EQ**: RB の EQ HI / MID / LOW を回すと EQ Three の
      各ゲインが動く。ツマミ中央で音がフラットに聞こえるか
      （= 正規化値 0.5 が 0 dB になっているか）も耳で確認する
- [ ] **FILTER**: 左半分でローパス（こもっていく）、右半分で
      ハイパス（細くなっていく）、中央で素通りになる
- [ ] **ジョグ**: 再生中のクリップがジョグで前後にヌッジされる。
      方向と量の感覚をメモしておく（後で効き具合を調整する材料）
- [ ] **PLAY / CUE / パッド / LED**: 前回と同じく効くこと。
      PLAY LED はクリップが実際に再生開始した時点で点く
      （クオンタイズ分遅れるのは仕様）
- [ ] **オートメーション録音**: オートメーション・アームを ON に
      して Arrangement 録音し、スクリプト経由でフェーダーを
      10 秒ほど動かす。Arrangement にエンベロープの線が出れば OK

## 8. トラブル時の見分け表

| 症状 | 疑う所 |
|---|---|
| コントロールサーフェイス一覧に MixCraft が出ない | `C:\ProgramData\Ableton\Live 10 Suite\Resources\MIDI Remote Scripts\` に MixCraft フォルダのコピーがあるか（Live 10 は User Library 側を読まない） |
| ノブ・ボタンが全部無反応 | rekordbox が起動したままになっていないか / サーフェイスの入力が DDJ-RB になっているか |
| EQ・FILTER・TRIM だけ効かない | そのデッキトラックに Utility / EQ Three / Auto Filter が入っているか |
| ヘッドホンにキューが来ない | 環境設定 → オーディオの Cue Out が 3/4 になっているか（Set ごとの設定） |
